# DSA 210 Data Science Project

## Motivation
Analysis of Istanbul's traffic based on weather.

## Data
IMM Traffic Data enriched with Weather API.

## Initial Findings
Based on the exploratory data analysis and hypothesis testing, initial findings indicate that weather conditions significantly impact traffic density. Specifically, the data shows that rainy weather increases traffic density by approximately 15% due to slower driving speeds and increased vehicle usage.
